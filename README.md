# Основы программирования на Python

+ В первой практической работе устанавливают Python на Windows и запускают `hello.py`.
+ Во второй работают с синтаксисом, вводом и выводом.
+ В третьей создают классы, атрибуты и методы.

## Локальный запуск

Для запуска нужен Bun 1.4.4.

```powershell
bun install --frozen-lockfile
bun run dev
```
